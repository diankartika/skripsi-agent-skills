# Nielsen's 10 Usability Heuristics

## H1 — Visibility of System Status

### Principle

The system should keep users informed about what is going on
through appropriate feedback within reasonable time.

### Look For

- loading indicators
- progress indicators
- confirmation messages
- current navigation state
- status feedback

### Typical Violations

- no indication that an action was successful
- unclear loading state
- unclear current location in the interface

---

## H2 — Match Between System and the Real World

### Principle

The system should use language, concepts, and conventions
familiar to the user.

### Look For

- terminology
- labels
- icons
- information ordering
- domain conventions

### Typical Violations

- technical terminology exposed to ordinary users
- unfamiliar labels
- icons whose meaning is unclear

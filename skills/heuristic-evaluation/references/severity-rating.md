# Severity Rating

Use a 0–4 severity scale.

## 0 — No Problem

No usability problem is identified.

## 1 — Cosmetic

A minor issue that does not significantly affect usability.

## 2 — Minor

A usability problem that may cause some difficulty but does
not substantially prevent task completion.

## 3 — Major

A significant usability problem that can substantially
interfere with task completion.

## 4 — Catastrophic

A critical usability problem that prevents users from
completing an important task or causes severe consequences.
